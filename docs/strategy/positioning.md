# Positioning: workbench for uncovering hunches

## Frame

GraphForge for VS Code is the **editor workbench for the GraphForge engine** — a
place to explore and uncover hunches with Cypher, analyst verbs, progressive
ontology, and epistemic context.

It is **not** a Neo4j Browser substitute, multi-user graph server UI, or generic
database admin console.

## Emotional positioning

| We are | We are not |
|---|---|
| Exploring and uncovering hunches | Operating a brittle graph appliance |
| Curious, supported discovery | Complex setup theater |
| Clear results and clear failures | Silent hangs and opaque waits |
| Concierge on-ramp (tool for GraphForge) | Brand-page marketing voice in the IDE |

## Competitive contrast (feeling lens)

Against typical graph UIs and notebook-only workflows: competitors often feel like
admin consoles or raw REPL homework. GraphForge’s extension should feel like a
**guided investigation bench** — simple, sturdy, and oriented to the next question.

Detailed competitive landscape (features, pricing, segments) is out of scope until
discovery fills it; this file only locks the feeling-led frame.

## Open
